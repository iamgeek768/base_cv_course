# ЭУМК «Основы компьютерного зрения»

Электронный учебно-методический комплекс в виде статического сайта (HTML, CSS, JavaScript).

## Состав

| Файл | Содержимое |
|---|---|
| `index.html` | Главная: аннотация, разделы курса, интерактивная демонстрация свёртки |
| `program.html` | Рабочая учебная программа: цель, задачи, результаты, разделы и часы, краткое содержание, инструменты, формы контроля |
| `section-1.html` … `section-6.html` | Теория по разделам со ссылками на литературу, контрольные вопросы, упражнения, пример выполнения |
| `test.html` | 22 тестовых задания, автоматическая проверка, шкала оценивания |
| `practice.html` | 5 практических работ, критерии и шкала оценивания |
| `sources.html` | Список литературы |
| `guide.html` | Руководство пользователя |
| `author.html` | Сведения об авторе |
| `assets/` | Стили (`style.css`) и скрипты (`site.js` — тема, меню, демонстрация свёртки; `test.js` — проверка теста) |
