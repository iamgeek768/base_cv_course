О разработке

Комплекс разработан в рамках задания на создание учебно-методического комплекса для электронного обучения. В него входят рабочая учебная программа, теоретический материал по шести разделам со ссылками на литературу, контрольные вопросы и упражнения с примерами решения, итоговый тест из 22 заданий и пять практических работ с критериями оценивания.

Инструменты разработки

  • HTML5 и CSS3 — структура и оформление страниц, адаптивная вёрстка для компьютеров и телефонов;
  • JavaScript без сторонних библиотек — проверка теста, демонстрация свёртки, переключение темы;
  • GitHub Pages — бесплатный хостинг статического сайта.

Сайт не требует сервера и базы данных: все страницы открываются и из локальной папки, и по ссылке в интернете.
