Классификация на основе свёрток

Свёрточная нейронная сеть не получает ядра от человека, а подбирает их сама по размеченным примерам. Раздел объясняет, из чего она состоит, как обучается и какие архитектуры стали классикой.

Постановка задачи

В задаче классификации модель получает изображение и возвращает один из C заранее известных классов: «кошка», «собака», «автомобиль» и так далее. Последний слой сети выдаёт C чисел — логитов zk. Функция softmax превращает их в вероятности, а обучение минимизирует кросс-энтропию между предсказанием и правильным классом y [5, гл. 6; 7]:

pk = ezk / Σj ezj, L = −log py

Почему не обычная полносвязная сеть? Изображение 224 × 224 × 3 — это 150 528 входных чисел. Один полносвязный слой из 1000 нейронов потребовал бы около 150 миллионов весов, при этом сеть не знала бы, что соседние пиксели связаны между собой. Свёрточный слой решает обе проблемы [5, гл. 9; 6]:

  • локальная связность — каждый выход зависит только от небольшой окрестности входа;
  • разделение весов — одно и то же ядро применяется во всех позициях, поэтому параметров на порядки меньше;
  • эквивариантность к сдвигу — признак распознаётся в любом месте изображения.

Типичная сеть чередует блоки «свёртка → нормализация → ReLU → пулинг»: пространственный размер уменьшается, а число каналов растёт. Первые слои учатся находить границы и цветовые пятна, средние — текстуры и части объектов, последние — признаки целых объектов [7; 2, гл. 5].

Рецептивное поле

Рецептивное поле нейрона — область входного изображения, от которой зависит его значение. Два последовательных слоя 3 × 3 дают поле 5 × 5, три — 7 × 7. Три слоя 3 × 3 с C каналами содержат 27C² весов против 49C² у одного слоя 7 × 7 и вдобавок дают три нелинейности вместо одной. На этом наблюдении построена архитектура VGG [22].

Обучение

Данные делят на три части: обучающую выборку (по ней подбираются веса), валидационную (по ней выбираются гиперпараметры и момент остановки) и тестовую (на ней один раз измеряется итоговое качество).

Веса обновляются методом стохастического градиентного спуска по мини-батчам. Градиент функции потерь по всем весам вычисляет алгоритм обратного распространения ошибки [5, гл. 6, 8]:

w ← w − η · ∂L/∂w η — скорость обучения (learning rate), важнейший гиперпараметр. На практике используют SGD с моментом или Adam и постепенно уменьшают η по расписанию.

Переобучение и регуляризация

Сеть с миллионами параметров легко запоминает обучающие примеры. Признак переобучения — точность на обучающей выборке растёт, а на валидационной перестаёт расти или падает. Средства борьбы:

  • аугментация данных — случайные отражения, обрезки, повороты, изменение яркости и цвета; модель видит каждый пример в разных вариантах;
  • затухание весов (weight decay, L2-регуляризация);
  • dropout и ранняя остановка по валидационной метрике;
  • перенос обучения с большой выборки на маленькую.

Ключевые архитектуры

Развитие архитектур во многом связано с соревнованием ImageNet ILSVRC: 1,28 млн обучающих изображений, 1000 классов. Метрика top-5 error — доля изображений, у которых правильного класса нет среди пяти наиболее вероятных ответов.

Остаточные связи ResNet. До 2015 года добавление слоёв сверх 20–30 ухудшало качество даже на обучающей выборке: глубокую сеть было трудно оптимизировать. ResNet добавляет вход блока к его выходу. Если блоку нечего добавить, ему достаточно обучить F(x) ≈ 0, а градиент свободно проходит через сумму к ранним слоям. Это позволило обучать сети глубиной в сотни слоёв [14].

Перенос обучения

Признаки, выученные сетью на ImageNet, полезны и для других задач: границы, текстуры и формы универсальны. Поэтому вместо обучения с нуля берут предобученную сеть и заменяют её последний слой на новый с нужным числом классов [7; 9].

  • Извлечение признаков: все слои, кроме нового последнего, заморожены. Подходит, когда данных совсем мало.
  • Дообучение (fine-tuning): обучается вся сеть с маленькой скоростью обучения. Даёт лучшее качество при сотнях и тысячах примеров.
import torch.nn as nn
from torchvision import models

model = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)
for p in model.parameters():
    p.requires_grad = False                     # заморозить признаки
model.fc = nn.Linear(model.fc.in_features, 5)   # новая «голова» на 5 классов

Метрики качества

Для каждого класса по матрице ошибок считают истинно положительные (TP), ложноположительные (FP) и ложноотрицательные (FN) ответы [20]:

Precision = TP / (TP + FP) Recall = TP / (TP + FN) F1 = 2 · P · R / (P + R)

Accuracy — доля верных ответов среди всех. На несбалансированных данных она обманчива: если 95 % снимков здоровые, модель, всегда отвечающая «здоров», получит accuracy 95 % при нулевой полноте по больным. В таких случаях смотрят на precision, recall и F1 по каждому классу.

Пример: сеть для CIFAR-10

import torch, torch.nn as nn

class SmallCNN(nn.Module):
    def __init__(self, n_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1), nn.BatchNorm2d(32), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(32, 64, 3, padding=1), nn.BatchNorm2d(64), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(64, 128, 3, padding=1), nn.BatchNorm2d(128), nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),
        )
        self.head = nn.Linear(128, n_classes)

    def forward(self, x):
        return self.head(self.features(x).flatten(1))

model = SmallCNN()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
loss_fn = nn.CrossEntropyLoss()

for images, labels in train_loader:      # одна эпоха обучения
    opt.zero_grad()
    loss = loss_fn(model(images), labels)
    loss.backward()
    opt.step()

Пример выполнения упражнения 4.1

Свёртка 3 × 3 с отступом 1 и шагом 1 сохраняет пространственный размер, MaxPool(2) уменьшает его вдвое. Параметры свёртки считаются по формуле Cout · (Cin · 9 + 1), полносвязного слоя — вход · выход + выход.

Видно, что 80 % параметров приходится на единственный полносвязный слой. Поэтому в современных сетях перед классификатором ставят глобальный пулинг: он сократил бы вход линейного слоя до 32 чисел, а число его параметров — до 330.

import torch.nn as nn
net = nn.Sequential(
    nn.Conv2d(3, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Flatten(), nn.Linear(32 * 8 * 8, 10))
print(sum(p.numel() for p in net.parameters()))   # 25578
