Свёртки

Свёртка — операция, которая объединяет классическую фильтрацию и свёрточные нейронные сети. Размытие, выделение границ и первый слой нейросети вычисляются одинаково, отличаются лишь числа в ядре.

Определение свёртки

Пусть I — изображение, а K — небольшая матрица весов, называемая ядром (kernel) или фильтром. Дискретная двумерная свёртка определяется так [1, гл. 3; 5, гл. 9]:

(I ∗ K)(i, j) = Σm Σn I(i − m, j − n) · K(m, n)

На практике ядро «прикладывают» к окрестности пикселя, перемножают совпавшие значения и складывают произведения. Затем окно сдвигается к следующему пикселю. Знаки «минус» в определении означают, что ядро перед этим поворачивается на 180°.

Операция без поворота ядра называется взаимной корреляцией:

(I ⋆ K)(i, j) = Σm Σn I(i + m, j + n) · K(m, n)

Для симметричных ядер (гауссова, усредняющего) результаты совпадают. В нейросетевых библиотеках слой, который называется свёрточным, на самом деле вычисляет корреляцию: веса ядра всё равно обучаются, и поворот ничего не меняет [5, гл. 9; 7]. Далее в курсе, следуя этой традиции, под свёрткой понимается именно корреляция, если не оговорено иное.

Размер ядра, шаг и отступ

Результат свёртки зависит от четырёх параметров:

  • размер ядра K — обычно нечётный (3, 5, 7), чтобы у ядра был центр;
  • шаг (stride) S — на сколько пикселей сдвигается окно; при S = 2 выход уменьшается примерно вдвое;
  • отступ (padding) P — сколько пикселей добавляется по краям входа;
  • расширение (dilation) D — расстояние между элементами ядра; при D > 1 ядро «видит» большую область без роста числа весов.
O = ⌊(N + 2P − D·(K − 1) − 1) / S⌋ + 1 N — размер входа по одной оси, O — размер выхода. При D = 1 формула упрощается до O = ⌊(N + 2P − K) / S⌋ + 1.

Если нужно сохранить размер (O = N) при S = 1, берут P = (K − 1) / 2; такой режим называют same. Режим без отступа называют valid: выход меньше входа на K − 1 [7].

Закономерность: если сумма весов равна 1, средняя яркость сохраняется (сглаживание, резкость). Если сумма равна 0, на однородных участках результат нулевой, а ненулевой отклик появляется только там, где яркость меняется (детекторы границ).

Свойства свёртки

  • Линейность: (a·I₁ + b·I₂) ∗ K = a·(I₁ ∗ K) + b·(I₂ ∗ K).
  • Эквивариантность к сдвигу: если сдвинуть изображение, результат сдвинется так же. Именно поэтому свёрточная сеть находит признак в любом месте кадра.
  • Коммутативность и ассоциативность: (I ∗ K₁) ∗ K₂ = I ∗ (K₁ ∗ K₂) — несколько линейных фильтров можно заменить одним. Это верно для настоящей свёртки, но не для корреляции.
  • Сепарабельность: некоторые ядра раскладываются в произведение столбца на строку. Например, гауссово ядро 3 × 3 = [1 2 1]ᵀ · [1 2 1] / 16. Тогда двумерная свёртка заменяется двумя одномерными, и число умножений на пиксель падает с K² до 2K [2, гл. 3].

Теорема о свёртке

Свёртка в пространственной области соответствует поэлементному умножению в частотной области [1, гл. 4]:

𝓕{I ∗ K} = 𝓕{I} · 𝓕{K}

Для больших ядер выгоднее вычислить быстрое преобразование Фурье (БПФ) изображения и ядра, перемножить спектры и выполнить обратное преобразование. Теорема также объясняет, почему сглаживающие фильтры называют низкочастотными: они подавляют высокие частоты, то есть мелкие детали и шум.

Многоканальная свёртка

Цветное изображение имеет 3 канала, а промежуточные карты признаков в нейросети — десятки и сотни. Ядро свёрточного слоя имеет размер Cin × K × K: оно охватывает все входные каналы сразу, а результаты по каналам суммируются в одно число. Чтобы получить Cout выходных каналов, слой содержит Cout таких ядер [7; 5, гл. 9].

Число параметров = Cout · (Cin · K · K + 1) «+1» — смещение (bias) каждого выходного канала. Пример: слой 3 → 64 канала с ядром 3 × 3 содержит 64 · (3 · 9 + 1) = 1792 параметра.

Особый случай — свёртка 1 × 1: она не смотрит на соседей, а смешивает каналы в каждой точке. Её используют для изменения числа каналов в архитектурах GoogLeNet и ResNet [14].

import torch, torch.nn as nn
conv = nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3, stride=1, padding=1)
x = torch.randn(1, 3, 224, 224)           # пакет из одного RGB-изображения
print(conv(x).shape)                      # torch.Size([1, 64, 224, 224])
print(sum(p.numel() for p in conv.parameters()))   # 1792

Ядро вычитает сумму правого столбца окна из суммы левого столбца: средний столбец весов нулевой. Выход в режиме valid имеет размер (4 − 3) + 1 = 2 по каждой оси.

  • Окно (1, 1), строки 1–3, столбцы 1–3: левый столбец 3 + 4 + 5 = 12, правый 0 + 1 + 0 = 1, результат 11.
  • Окно (1, 2), столбцы 2–4: левый 1 + 2 + 3 = 6, правый 2 + 0 + 1 = 3, результат 3.
  • Окно (2, 1), строки 2–4: левый 4 + 5 + 2 = 11, правый 1 + 0 + 1 = 2, результат 9.
  • Окно (2, 2): левый 2 + 3 + 4 = 9, правый 0 + 1 + 0 = 1, результат 8.

Большие положительные значения в левом столбце результата показывают, что слева направо яркость падает — ядро нашло вертикальный перепад. При настоящей свёртке ядро сначала поворачивается на 180°, его столбцы меняются местами, и все значения меняют знак: −11, −3, −9, −8.

Размер выхода: O = ⌊(32 + 2·2 − 5) / 2⌋ + 1 = ⌊31 / 2⌋ + 1 = 15 + 1 = 16.

import numpy as np
I = np.array([[3, 1, 0, 2], [4, 2, 1, 0], [5, 3, 0, 1], [2, 4, 1, 0]])
K = np.array([[1, 0, -1]] * 3)
out = np.array([[(I[i:i+3, j:j+3] * K).sum() for j in range(2)] for i in range(2)])
print(out)   # [[11  3]
             #  [ 9  8]]
