Классические методы обработки изображений

До появления нейросетей изображения обрабатывали явно заданными формулами. Эти методы и сегодня используются для предобработки, в задачах с малым количеством данных и на слабых устройствах.

Точечные преобразования яркости

Точечное преобразование меняет яркость каждого пикселя независимо от соседей: s = T(r), где r — исходная яркость, s — новая [1, гл. 3].

  • Негатив: s = 255 − r. Полезен для рентгеновских и медицинских снимков.
  • Линейное контрастирование: растягивает диапазон яркостей на весь интервал 0…255.
  • Гамма-коррекция: при γ < 1 высветляет тёмные области, при γ > 1 затемняет светлые.
s = (r − rmin) / (rmax − rmin) · 255 s = 255 · (r / 255)γ

Бинаризация и метод Оцу

Бинаризация превращает полутоновое изображение в двухцветное: пиксели ярче порога t становятся белыми (объект), остальные — чёрными (фон). Главный вопрос — как выбрать t.

Метод Оцу [11] перебирает все пороги и выбирает тот, при котором межклассовая дисперсия максимальна, то есть два класса пикселей разделены лучше всего:

σB2(t) = ω0(t) · ω1(t) · (μ0(t) − μ1(t))2 → max ω0, ω1 — доли пикселей ниже и выше порога, μ0, μ1 — средние яркости этих классов.

Метод хорошо работает, если гистограмма двухмодальная. При неравномерном освещении применяют адаптивную бинаризацию: порог вычисляется отдельно для окрестности каждого пикселя (cv2.adaptiveThreshold) [8].

Эквализация гистограммы

Эквализация перераспределяет яркости так, чтобы гистограмма стала близкой к равномерной. Преобразованием служит накопленная (кумулятивная) функция распределения [1, гл. 3]:

sk = 255 · Σj=0…k p(j)

Глобальная эквализация может чрезмерно усилить шум в однородных областях. Метод CLAHE (Contrast Limited Adaptive Histogram Equalization) выполняет эквализацию в небольших плитках и ограничивает усиление контраста, поэтому даёт более естественный результат.

Пространственный фильтр вычисляет новое значение пикселя по его окрестности. Линейные фильтры реализуются свёрткой с ядром — подробно эта операция разобрана в разделе 3.

Выделение границ

Граница — место резкого изменения яркости. Изменение описывается градиентом — вектором частных производных (Gx, Gy). На дискретном изображении производные приближаются разностями, которые удобно записать ядрами [1, гл. 10; 3, гл. 8].

Оператор Лапласа — вторая производная: он реагирует на границы в любом направлении, но очень чувствителен к шуму, поэтому его применяют после гауссова сглаживания (фильтр LoG).

Детектор Кэнни

Детектор Джона Кэнни [10] — стандарт выделения тонких связных границ. Он состоит из четырёх шагов:

  1. сглаживание гауссовым фильтром для подавления шума;
  2. вычисление модуля и направления градиента, например операторами Собеля;
  3. подавление немаксимумов: пиксель остаётся, только если модуль градиента в нём максимален вдоль направления градиента — так границы становятся толщиной в один пиксель;
  4. двойной порог и гистерезис: пиксели выше верхнего порога — сильные границы, между порогами — слабые; слабые сохраняются, только если связаны с сильными.
edges = cv2.Canny(gray, threshold1=50, threshold2=150)

Морфологические операции

Морфология обрабатывает форму объектов на бинарных изображениях с помощью структурного элемента — небольшой маски, например квадрата 3 × 3 или диска [1, гл. 9; 4, гл. 3].

  • Эрозия — пиксель остаётся белым, только если весь структурный элемент вокруг него лежит на объекте. Объекты утончаются, мелкие исчезают.
  • Дилатация — пиксель становится белым, если структурный элемент задевает объект хотя бы одним пикселем. Объекты утолщаются, мелкие разрывы заполняются.
  • Размыкание (opening) = эрозия, затем дилатация. Удаляет мелкий шум, сохраняя размер крупных объектов.
  • Замыкание (closing) = дилатация, затем эрозия. Закрывает небольшие дыры и разрывы контуров.

Геометрические преобразования

Масштабирование, поворот, сдвиг и наклон описываются аффинным преобразованием с матрицей 2 × 3; оно сохраняет параллельность прямых и определяется тремя парами соответствующих точек. Перспективное преобразование (гомография) задаётся матрицей 3 × 3, определяется четырьмя парами точек и позволяет, например, «выпрямить» сфотографированный под углом документ [2, гл. 3].

Координаты после преобразования обычно нецелые, поэтому значение пикселя находят интерполяцией: по ближайшему соседу (быстро, но ступенчато), билинейной (по 4 соседям) или бикубической (по 16 соседям, наиболее гладко).

Особые точки и преобразование Хафа

Чтобы сопоставлять изображения — склеивать панорамы, отслеживать объекты, — находят особые точки: углы и пятна, которые надёжно обнаруживаются на разных снимках одной сцены. Детектор Харриса находит углы по собственным значениям матрицы вторых моментов градиента. Метод SIFT [31] строит для каждой точки дескриптор, устойчивый к масштабу и повороту; ORB — его быстрая свободная альтернатива [2, гл. 7].

Преобразование Хафа находит прямые и окружности. Каждая граничная точка «голосует» за все прямые ρ = x·cos θ + y·sin θ, проходящие через неё; прямые, набравшие много голосов, считаются найденными [1, гл. 10].

Усреднение «размазало» выброс: центральный пиксель (39) по-прежнему заметно светлее соседей, а помеха к тому же повлияла на результат фильтра в восьми соседних позициях. import numpy as np
w = np.array([10, 12, 11, 13, 255, 12, 11, 10, 14])
print(round(w.mean()), int(np.median(w)))   # 39 12
