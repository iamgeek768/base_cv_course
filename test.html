Итоговый тест

22 задания по всем шести разделам курса. Отметьте ответы и нажмите «Проверить ответы» внизу страницы: результат и разбор ошибок появятся сразу.

Правила и шкала оценивания

В заданиях встречаются блоки ответов разного состава: с одним верным вариантом из трёх–шести, с несколькими верными вариантами и такие, где верны все варианты. Тип задания указан под его текстом:

  • «Выберите один ответ» — верный вариант ровно один;
  • «Выберите все верные ответы» — верных вариантов может быть один, несколько или все.

Критерий оценивания задания: за каждое задание начисляется 1 балл, если выбранный набор ответов полностью совпадает с правильным. Частично верный ответ, лишний или пропущенный вариант оцениваются в 0 баллов. Максимум — 22 балла.

БаллыДоля верных ответовОценка
19–2285 % и болееотлично
16–1870–84 %хорошо
13–1555–69 %удовлетворительно
0–12менее 55 %неудовлетворительно

Процент верных ответов входит в итоговую оценку по курсу с весом 40 % (см. формы контроля).

Задания

1.Сколько уровней яркости можно закодировать при глубине 8 бит на канал?

Выберите один ответ (раздел 1)

28 = 256 уровней: от 0 до 255 включительно.

2.Какие утверждения о представлении изображений в OpenCV верны?

Выберите все верные ответы (раздел 1)

Ось строк направлена вниз, а каналы OpenCV хранит в порядке BGR.

3.Какие форматы сохраняют изображение без потери качества?

Выберите все верные ответы (раздел 1)

JPEG и WebP с потерями отбрасывают часть информации; PNG, BMP и TIFF (без сжатия или с LZW) — нет.

4.Какой канал имеет наибольший вес при переводе RGB-изображения в оттенки серого по стандарту BT.601?

Выберите один ответ (раздел 1)

Y = 0,299R + 0,587G + 0,114B: глаз наиболее чувствителен к зелёному.

5.Какой фильтр лучше всего подавляет импульсный шум «соль и перец», сохраняя границы?

Выберите один ответ (раздел 2)

Медиана не учитывает одиночные экстремальные значения, а линейные фильтры «размазывают» их по окрестности.

6.Какие шаги входят в алгоритм детектора границ Кэнни?

Выберите все верные ответы (раздел 2)

Верны все четыре варианта — это и есть четыре шага алгоритма.

7.Какой критерий оптимизирует метод Оцу при выборе порога бинаризации?

Выберите все верные ответы (раздел 2)

Оцу максимизирует межклассовую дисперсию, что равносильно минимизации внутриклассовой.

8.Какая морфологическая операция удаляет мелкие белые точки шума, почти не меняя размер крупных объектов?

Выберите один ответ (раздел 2)

Размыкание — эрозия, затем дилатация: эрозия убирает мелкие точки, дилатация возвращает крупным объектам прежний размер.

9.Изображение 28 × 28 сворачивается с ядром 5 × 5 без отступа с шагом 1. Каков размер выхода?

Выберите один ответ (раздел 3)

O = (28 + 0 − 5) / 1 + 1 = 24.

10.У каких ядер сумма весов равна нулю?

Выберите все верные ответы (раздел 3)

Ядра-детекторы границ дают ноль на однородных участках. У сглаживающих ядер и ядра резкости сумма равна 1.

11.Какими свойствами обладает двумерная дискретная свёртка?

Выберите все верные ответы (раздел 3)

Верны все три варианта.

12.Сколько обучаемых параметров у слоя nn.Conv2d(3, 64, kernel_size=3) со смещением?

Выберите один ответ (раздел 3)

64 · (3 · 3 · 3 + 1) = 64 · 28 = 1792. Ответ 1728 не учитывает смещения.

13.Какие утверждения о свёрточном слое nn.Conv2d в PyTorch верны?

Выберите все верные ответы (раздел 3)

Ядро не поворачивается; параметры зависят только от числа каналов и размера ядра; свёртка 1 × 1 как раз и используется для изменения числа каналов.

14.Какие приёмы помогают бороться с переобучением свёрточной сети?

Выберите все верные ответы (раздел 4)

Дополнительные эпохи, наоборот, усиливают переобучение.

15.Какая идея позволила обучать сети глубиной более ста слоёв?

Выберите один ответ (раздел 4)

Остаточные связи ResNet обеспечивают прохождение градиента к ранним слоям.

16.Что верно для переноса обучения с ImageNet на свою задачу?

Выберите все верные ответы (раздел 4)

Признаки ImageNet универсальны и полезны для задач с совсем другими классами, например медицинских.

17.Чему равен IoU рамок A = (0, 0, 4, 4) и B = (2, 0, 6, 4) в формате (xmin, ymin, xmax, ymax)?

Выберите один ответ (раздел 5)

Пересечение 2 · 4 = 8, объединение 16 + 16 − 8 = 24, IoU = 8/24 = 1/3.

18.Какие из детекторов относятся к одностадийным?

Выберите все верные ответы (раздел 5)

R-CNN и Faster R-CNN сначала предлагают области, затем их классифицируют, то есть являются двухстадийными.

19.Для чего в детекторах применяют алгоритм подавления немаксимумов (NMS)?

Выберите все верные ответы (раздел 5)

NMS оставляет из сильно перекрывающихся рамок одну — с наибольшей уверенностью.

20.Какие архитектуры предназначены для сегментации изображений?

Выберите все верные ответы (раздел 6)

AlexNet — классификатор, первая версия YOLO — детектор.

21.Предсказанная маска содержит 4 пикселя, истинная — 6, общих пикселей 3. Чему равен коэффициент Dice?

Выберите один ответ (раздел 6)

Dice = 2 · 3 / (4 + 6) = 0,6. Значение 0,43 — это IoU = 3/7.

22.Какой вид сегментации различает отдельные объекты одного класса, но не размечает фоновые области вроде неба и дороги?

Выберите один ответ (раздел 6)

Семантическая не различает экземпляры, паноптическая размечает и экземпляры, и фон.
